# Expense Proxy

## Current Date and Time
**2026-02-18 18:07:04 (UTC)**

This project allows users to manage their expenses effectively. 

## Features
- Track expenses
- Categorize your expenses
- Generate reports

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/seanconrad1/expense-proxy.git
   ```
2. Navigate into the project directory:
   ```bash
   cd expense-proxy
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage

Start the application:
```bash
node server.js
```
